## О проекте

Synchro Nova — легковесная альтернатива громоздким оверлеям и твикерам, перегружающим систему и конфликтующим с античитами. Приложение объединяет аппаратное управление сочностью (Digital Vibrance), гамма-калибровку через LUT дисплея, аудит драйверов и системные твики Windows в едином интерфейсе без рекламы, телеметрии и фоновых служб.

---

## 🛡️ Безопасность и совместимость с античитами

Synchro Nova спроектирована с приоритетом на полную совместимость с соревновательными играми и античитами уровня ядра (Easy Anti-Cheat, BattlEye, Riot Vanguard, Ricochet, VAC):

- **Изоляция процессов**: Приложение работает строго в User Mode как независимый системный процесс. Оно не открывает дескрипторы игр и не обращается к их памяти (0 обращений через `PROCESS_VM_READ` или `PROCESS_VM_WRITE`).
- **Отсутствие графических перехватов**: Synchro Nova не перехватывает графический конвейер (DirectX / Vulkan SwapChain) и не внедряет динамические библиотеки в игровые клиенты.
- **Отсутствие синтетического ввода**: В кодовой базе отсутствуют вызовы симуляции клавиатуры и мыши (`SendInput`, `keybd_event`, глобальные хуки окон).
- **Штатные интерфейсы Windows**: Калибровка цвета выполняется через официальные WinAPI-интерфейсы Desktop Window Manager (`MagSetFullscreenColorEffect`) и аппаратные таблицы гаммы дисплея (`SetDeviceGammaRamp`), аналогично стандартным панелям управления NVIDIA Control Panel и AMD Software.
- **Системные политики защиты**: При старте процесса активируются политики постоянного DEP (Data Execution Prevention), безопасного разрешения библиотек (защита от DLL Search Order Hijacking) и контроль целостности структур кучи.

## Основные возможности

### 1. Аппаратная цветокоррекция
- **Управление через Windows GDI & Magnification API**: регулировка сочности (vibrance), насыщенности, гаммы, контраста и цветового тона без задержки кадра и без инпут-лага.
- **Режим Black Holo**: интеллектуальная калибровка динамического диапазона и теней для улучшения видимости в темных сценах без пересвета светлых зон.
- **Профили для игр**: автоматическая привязка параметров калибровки к установленным играм.
- **Адаптивный акцент интерфейса**: поддержка пользовательских RGB-цветов темы с динамическим вычислением контрастности текста.

### 2. Системные твики и оптимизация отклика
- **Проверенные параметры**: оптимизация системного таймера, приоритеты MMCSS, полноэкранная оптимизация (FSO), отключение телеметрии и оптимизация сетевого стека TCP.
- **Точки восстановления Windows и бекапы реестра**: автоматическое создание точки восстановления системы Windows (`SRSetRestorePointW`) и снимка реестра (`.reg`) перед внесением изменений.
- **Прозрачность и безопасность**: каждая команда и ключ реестра документированы в интерфейсе и в [справочнике по твикам](docs/TWEAKS_REFERENCE.md). При запуске без прав администратора системные настройки защищены блокировкой и эффектом матового размытия.

### 3. Анализ оборудования и драйверов
- Определение активного графического адаптера, текущей версии драйвера и даты его выпуска.
- Проверка актуальности драйверов NVIDIA, AMD, Intel с прямыми ссылками на официальные источники.
- Мониторинг загрузки процессора и оперативной памяти через нативный Windows PDH (Performance Data Helper).

## Скачать и установить

Свежие сборки доступны на странице [**Releases**](https://github.com/Arean-Max/synchro-nova/releases):

- **Портативная версия (`Synchro-Nova-2.2.3-Portable.zip`)** — автономный бинарник `synchro.exe`, запускается без установки из любой папки или с накопителя.
- **Установщик (`Synchro.Nova_2.2.3_x64-setup.exe`)** — инсталлятор с ярлыками, интеграцией в системный поиск Windows и деинсталлятором.

### Проверка контрольной суммы (SHA-256)
Для проверки целостности загруженного файла в PowerShell:
```powershell
Get-FileHash .\synchro.exe -Algorithm SHA256
```

## Сборка из исходников

### Требования
- [Node.js](https://nodejs.org/) (версия 18+)
- [Rust](https://www.rust-lang.org/) (stable `x86_64-pc-windows-gnu` или `x86_64-pc-windows-msvc`)
- [Tauri CLI](https://tauri.app/)

### Инструкция по сборке
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Arean-Max/synchro-nova.git
cd synchro-nova

# 2. Установите зависимости
npm install

# 3. Запуск в режиме разработки
npm run dev

# 4. Сборка портативной версии
npm run build:portable

# 5. Сборка релизного инсталлятора
npm run build
```

Собранный исполняемый файл создается в `src-tauri/target/release/synchro.exe`, а установщик — в `src-tauri/target/release/bundle/nsis/`.
