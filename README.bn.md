### Synchro Nova কি করে?

সংক্ষেপে: এটি একটি হালকা ওজনের, বিনামূল্যের ইউটিলিটি যা গেমগুলিতে রঙের প্রাণবন্ততা এবং বৈপরীত্য বাড়ায়, শত্রুদের অন্ধকার পরিবেশের বিরুদ্ধে দাঁড়াতে সাহায্য করে।

- **স্বয়ংক্রিয় প্রতি গেম প্রোফাইল**: একবার আপনার গেমের জন্য আপনার প্রিয় ভাইব্রেন্স লেভেল সেট করুন। আপনি যখন CS2, Valorant, বা Apex চালু করেন, তখন রং স্বয়ংক্রিয়ভাবে শুরু হয়। আপনি যখন অল্ট-ট্যাব বা প্রস্থান করেন, আপনার ডিসপ্লের রঙ অবিলম্বে স্বাভাবিক অবস্থায় ফিরে আসে যাতে ডেস্কটপে বা আপনার ব্রাউজারে আপনার চোখ ব্যাথা না হয়।
- **বিলম্ব এবং প্রতিক্রিয়াশীলতা**: পরীক্ষিত, নিরাপদ উইন্ডোজ প্রতিক্রিয়াশীলতা পরিবর্তন (টাইমার রেজোলিউশন, কাঁচা মাউস ইনপুট, নেটওয়ার্ক প্যাকেট হ্যান্ডলিং) অন্তর্ভুক্ত করে যাতে ইনপুট চটকদার হয়।
- **জিরো রিসোর্স টেনে আনুন**: সম্পূর্ণ অ্যাপটি 5 MB এর নিচে, মিলিসেকেন্ডে খোলে এবং মাত্র ~2 MB RAM ব্যবহার করে আপনার ট্রেতে বসে।

### কিভাবে ডাউনলোড করবেন এবং চালাবেন (শিশুর নির্দেশিকা)

আপনি যদি প্রথমবার GitHub পরিদর্শন করেন, তাহলে এখানে ঠিক কী করতে হবে:

1. উপর মাথা [**Releases**](https://github.com/Arean-Max/synchro-nova/releases) পৃষ্ঠা (বা ডান সাইডবারে "রিলিজ" এ ক্লিক করুন)।
2. সর্বশেষ প্রকাশের অধীনে, ডাউনলোড করুন:
   - **`synchro.exe`** — **বহনযোগ্য সংস্করণ (প্রস্তাবিত)**. এটি যেকোন ফোল্ডারে ডাউনলোড করুন এবং চালানোর জন্য ডাবল ক্লিক করুন। কোন সেটআপ প্রয়োজন.
   - বা **`Synchro.Nova_*_x64-setup.exe`** — স্ট্যান্ডার্ড উইন্ডোজ ইনস্টলার যদি আপনি ডেস্কটপ এবং স্টার্ট মেনু শর্টকাট পছন্দ করেন।
3. **যদি উইন্ডোজ একটি নীল পপআপ দেখায় ("উইন্ডোজ আপনার পিসি সুরক্ষিত" / স্মার্টস্ক্রিন)**:
   - এটি সমস্ত বিনামূল্যের ওপেন-সোর্স সরঞ্জামগুলির সাথে ঘটে যা Microsoft থেকে একটি ব্যয়বহুল $500/বছরের এন্টারপ্রাইজ শংসাপত্র কেনে না৷
   - ক্লিক করুন **"আরো তথ্য"**, তারপর ক্লিক করুন **"যাই হোক চালান"**.
   - সম্পূর্ণ সোর্স কোডটি এখানে গিটহাবে 100% খোলা আছে — কোন অ্যাডওয়্যার, কোন টেলিমেট্রি, কোন বাজে কথা নয়।

### দ্রুত শুরু (1-মিনিট সেটআপ)

1. লঞ্চ **Synchro Nova**.
2. যান **"রঙ"** ট্যাব করুন এবং আপনার ভাইব্রেন্স লেভেল বেছে নিন (যেমন `150%` বা `200%`).
3. এটিকে আপনার গেমের সাথে লিঙ্ক করুন (অ্যাপটি চলমান গেমগুলি স্বয়ংক্রিয়ভাবে সনাক্ত করে, অথবা আপনি বেছে নিতে পারেন `.exe` ম্যানুয়ালি)।
4. তাই তো! ট্রেতে ছোট করুন এবং খেলুন।

### FAQ

#### আমি কি CS2, Valorant, Rust, বা Faceit-এ নিষিদ্ধ হব?
**100% না। নিষেধাজ্ঞার ঝুঁকি শূন্য।**  
Synchro Nova **গেম মেমরি স্পর্শ করে না, প্রক্রিয়াগুলিতে DLL ইনজেক্ট করে না এবং গেম ওভারলে আঁকে না**. এটি শুধুমাত্র স্ট্যান্ডার্ড Windows APIs (DWM এবং GPU ড্রাইভার) এর মাধ্যমে ডেস্কটপ গামা সামঞ্জস্য করে — ঠিক যেমন NVIDIA বা AMD কন্ট্রোল প্যানেলে ডিজিটাল ভাইব্রেন্স স্লাইডার টেনে আনা। অ্যান্টি-চিট ইঞ্জিন (VAC, Faceit, Vanguard, Easy Anti-cheat, BattlEye) ডেস্কটপের রঙ পরিবর্তন করে না।

#### কেন শুধু NVIDIA বা AMD কন্ট্রোল প্যানেল ব্যবহার করবেন না?
আপনি যখন একটি গেম চালু বা বন্ধ করেন তখন GPU কন্ট্রোল প্যানেল স্বয়ংক্রিয়ভাবে রঙ টগল করে না। আপনি যদি সেখানে স্পন্দন তৈরি করেন তবে আপনার সম্পূর্ণ উইন্ডোজ ডেস্কটপ এবং ব্রাউজার অতিরিক্ত স্যাচুরেটেড থাকবে। ফ্লাইতে সিঙ্ক্রো এটি স্বয়ংক্রিয়ভাবে পরিচালনা করে: গেম চলমান = সমৃদ্ধ রং; খেলা বন্ধ = পরিষ্কার ডেস্কটপ রং।

#### সিস্টেম tweaks জগাখিচুড়ি আমার উইন্ডোজ আপ?
না। সমস্ত টুইক স্ট্যান্ডার্ড, ভাল-ডকুমেন্টেড উইন্ডোজ প্যারামিটার ব্যবহার করে। কিছু পরিবর্তন করার আগে, Synchro Nova একটি Windows Restore Point এবং পরিবর্তিত রেজিস্ট্রি কীগুলির একটি ব্যাকআপ তৈরি করে। আপনি ক্লিক করে যেকোনো সময় উইন্ডোজ ডিফল্টে সবকিছু ফিরিয়ে আনতে পারেন **"রোলব্যাক পরিবর্তন"**.
