### Τι κάνει το Synchro Nova;

Εν ολίγοις: είναι ένα ελαφρύ, δωρεάν βοηθητικό πρόγραμμα που ενισχύει τη χρωματική ζωντάνια και την αντίθεση στα παιχνίδια, βοηθώντας τους εχθρούς να ξεχωρίζουν σε σκοτεινά περιβάλλοντα.

- **Αυτόματα προφίλ ανά παιχνίδι**: Ορίστε μια φορά το αγαπημένο σας επίπεδο δόνησης για το παιχνίδι σας. Όταν εκκινείτε τα CS2, Valorant ή Apex, τα χρώματα μπαίνουν αυτόματα. Όταν κάνετε alt-tab ή τερματίσετε, τα χρώματα της οθόνης σας επανέρχονται αμέσως στο κανονικό, ώστε τα μάτια σας να μην πονάνε στην επιφάνεια εργασίας ή στο πρόγραμμα περιήγησής σας.
- **Latency & Responsiveness**: Περιλαμβάνει δοκιμασμένες, ασφαλείς τροποποιήσεις ανταπόκρισης των Windows (ανάλυση χρονοδιακόπτη, ακατέργαστη είσοδο ποντικιού, διαχείριση πακέτων δικτύου) για να κάνει την είσοδο να αισθάνεται γρήγορη.
- **Μηδενική μεταφορά πόρων**: Ολόκληρη η εφαρμογή είναι κάτω από 5 MB, ανοίγει σε χιλιοστά του δευτερολέπτου και τοποθετείται στο δίσκο σας χρησιμοποιώντας μόλις ~2 MB μνήμης RAM.

### Πώς να κάνετε λήψη και εκτέλεση (Οδηγός για αρχάριους)

Εάν επισκέπτεστε το GitHub για πρώτη φορά, ορίστε ακριβώς τι πρέπει να κάνετε:

1. Κατευθυνθείτε προς το [**Releases**](https://github.com/Arean-Max/synchro-nova/releases) σελίδα (ή κάντε κλικ στο "Κυκλοφορίες" στη δεξιά πλαϊνή γραμμή).
2. Κάτω από την πιο πρόσφατη έκδοση, κάντε λήψη:
   - **`synchro.exe`** — **φορητή έκδοση (συνιστάται)**. Απλώς κατεβάστε το σε οποιονδήποτε φάκελο και κάντε διπλό κλικ για εκτέλεση. Δεν απαιτείται ρύθμιση.
   - Ή **`Synchro.Nova_*_x64-setup.exe`** — τυπικό πρόγραμμα εγκατάστασης των Windows, εάν προτιμάτε τις συντομεύσεις επιτραπέζιου υπολογιστή και μενού έναρξης.
3. **Εάν τα Windows εμφανίζουν ένα μπλε αναδυόμενο παράθυρο ("Τα Windows προστατεύουν τον υπολογιστή σας" / SmartScreen)**:
   - Αυτό συμβαίνει με όλα τα δωρεάν εργαλεία ανοιχτού κώδικα που δεν αγοράζουν ένα ακριβό εταιρικό πιστοποιητικό 500 $/έτος από τη Microsoft.
   - Κλικ **"Περισσότερες πληροφορίες"**, μετά κάντε κλικ **"Τρέξε πάντως"**.
   - Ολόκληρος ο πηγαίος κώδικας είναι 100% ανοιχτός εδώ στο GitHub — χωρίς adware, χωρίς τηλεμετρία, χωρίς ανοησίες.

### Γρήγορη εκκίνηση (Ρύθμιση 1 λεπτού)

1. Εκτόξευση **Synchro Nova**.
2. Πηγαίνετε στο **"Χρώμα"** καρτέλα και επιλέξτε το επίπεδο δόνησης (π.χ. `150%` ή `200%`).
3. Συνδέστε το με το παιχνίδι σας (η εφαρμογή εντοπίζει αυτόματα παιχνίδια που τρέχουν ή μπορείτε να επιλέξετε το `.exe` χειροκίνητα).
4. Αυτό είναι όλο! Ελαχιστοποιήστε το στο δίσκο και παίξτε.

### FAQ

#### Θα μου αποκλειστούν σε CS2, Valorant, Rust ή Faceit;
**100% Όχι. Ο κίνδυνος απαγόρευσης είναι μηδενικός.**  
Synchro Nova **δεν αγγίζει τη μνήμη παιχνιδιών, δεν εισάγει DLL σε διαδικασίες και δεν σχεδιάζει επικαλύψεις παιχνιδιών**. Προσαρμόζει το γάμμα επιφάνειας εργασίας μόνο μέσω τυπικών API των Windows (προγράμματα οδήγησης DWM και GPU) — ακριβώς όπως σύρετε το ρυθμιστικό Digital Vibrance στον πίνακα ελέγχου NVIDIA ή AMD. Οι μηχανές κατά της εξαπάτησης (VAC, Faceit, Vanguard, Easy Anti-Cheat, BattlEye) δεν επισημαίνουν αλλαγές χρώματος στην επιφάνεια εργασίας.

#### Γιατί να μην χρησιμοποιήσετε απλώς τον Πίνακα Ελέγχου NVIDIA ή AMD;
Οι πίνακες ελέγχου GPU δεν αλλάζουν αυτόματα τα χρώματα κατά την εκκίνηση ή το κλείσιμο ενός παιχνιδιού. Εάν ενεργοποιήσετε τη δόνηση εκεί, ολόκληρη η επιφάνεια εργασίας των Windows και το πρόγραμμα περιήγησής σας θα παραμείνουν υπερκορεσμένα. Το Synchro το χειρίζεται αυτόματα αμέσως: τρέχει το παιχνίδι = πλούσια χρώματα. παιχνίδι κλειστό = καθαρά χρώματα επιφάνειας εργασίας.

#### Οι τροποποιήσεις του συστήματος θα μπερδέψουν τα Windows μου;
Όχι. Όλες οι τροποποιήσεις χρησιμοποιούν τυπικές, καλά τεκμηριωμένες παραμέτρους των Windows. Πριν τροποποιήσετε οτιδήποτε, το Synchro Nova δημιουργεί ένα σημείο επαναφοράς των Windows και ένα αντίγραφο ασφαλείας των τροποποιημένων κλειδιών μητρώου. Μπορείτε να επαναφέρετε τα πάντα στις προεπιλογές των Windows ανά πάσα στιγμή κάνοντας κλικ **"Αλλαγές επαναφοράς"**.
