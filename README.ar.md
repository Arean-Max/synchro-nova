### ماذا تفعل سينكرو نوفا؟

باختصار: إنها أداة مجانية خفيفة الوزن تعمل على تعزيز حيوية الألوان وتباينها في الألعاب، مما يساعد الأعداء على التفوق في البيئات المظلمة.

- **ملفات التعريف التلقائية لكل لعبة**: قم بتعيين مستوى الحيوية المفضل لديك للعبتك مرة واحدة. عند تشغيل CS2، أو Valorant، أو Apex، تظهر الألوان تلقائيًا. عند الضغط على مفتاح Alt أو الخروج، تعود ألوان العرض على الفور إلى وضعها الطبيعي حتى لا تؤذي عيناك على سطح المكتب أو في متصفحك.
- **الكمون والاستجابة**: يتضمن تعديلات آمنة ومختبرة لاستجابة Windows (دقة المؤقت، وإدخال الماوس الخام، ومعالجة حزم الشبكة) لجعل الإدخال يبدو سريعًا.
- **سحب الموارد صفر**: يبلغ حجم التطبيق بأكمله أقل من 5 ميغابايت، ويتم فتحه بالمللي ثانية، ويتم وضعه في درجك باستخدام حوالي 2 ميغابايت فقط من ذاكرة الوصول العشوائي.

### كيفية التنزيل والتشغيل (دليل المبتدئين)

إذا كنت تزور GitHub للمرة الأولى، فإليك بالضبط ما يجب عليك فعله:

1. توجه إلى [**Releases**](https://github.com/Arean-Max/synchro-nova/releases) الصفحة (أو انقر فوق "الإصدارات" على الشريط الجانبي الأيمن).
2. ضمن الإصدار الأخير، قم بتنزيل:
   - **`synchro.exe`** — **النسخة المحمولة (مستحسن)**. فقط قم بتنزيله على أي مجلد وانقر نقرًا مزدوجًا للتشغيل. لا حاجة للإعداد.
   - أو **`Synchro.Nova_*_x64-setup.exe`** — مثبت Windows القياسي إذا كنت تفضل اختصارات سطح المكتب وقائمة البدء.
3. **إذا أظهر Windows نافذة منبثقة زرقاء ("Windows يحمي جهاز الكمبيوتر الخاص بك" / SmartScreen)**:
   - يحدث هذا مع جميع الأدوات المجانية مفتوحة المصدر التي لا تشتري شهادة مؤسسية باهظة الثمن بقيمة 500 دولار سنويًا من Microsoft.
   - انقر **"مزيد من المعلومات"**, ثم انقر فوق **"تشغيل على أي حال"**.
   - كود المصدر بالكامل مفتوح بنسبة 100% هنا على GitHub - لا توجد برامج إعلانية، ولا قياس عن بعد، ولا هراء.

---

### البدء السريع (الإعداد لمدة دقيقة واحدة)

1. يطلق **Synchro Nova**.
2. اذهب الى **"لون"** علامة التبويب واختيار مستوى الحيوية الخاص بك (على سبيل المثال. `150%` أو `200%`).
3. قم بربطه بلعبتك (يكتشف التطبيق تلقائيًا الألعاب الجاري تشغيلها، أو يمكنك اختيار `.exe` يدويا).
4. هذا كل شيء! تصغير إلى الدرج واللعب.

### التعليمات

#### هل سيتم حظري في CS2 أو Valorant أو Rust أو Faceit؟
**100% لا. خطر الحظر صفر.**  
Synchro Nova **لا يلمس ذاكرة اللعبة، ولا يُدخل ملفات DLL في العمليات، ولا يرسم تراكبات اللعبة**. فهو يضبط فقط جاما سطح المكتب عبر واجهات برمجة تطبيقات Windows القياسية (برامج تشغيل DWM وGPU) - تمامًا مثل سحب شريط تمرير Digital Vibrance في لوحة التحكم NVIDIA أو AMD. محركات مكافحة الغش (VAC، Faceit، Vanguard، Easy Anti-Cheat، BattlEye) لا تشير إلى تغيرات لون سطح المكتب.

#### لماذا لا تستخدم لوحة التحكم NVIDIA أو AMD فقط؟
لا تقوم لوحات تحكم GPU بتبديل الألوان تلقائيًا عند تشغيل اللعبة أو إغلاقها. إذا قمت بزيادة الحيوية هناك، فسيظل سطح مكتب Windows والمتصفح بالكامل مشبعين. يعالج Synchro هذا تلقائيًا أثناء التنقل: تشغيل اللعبة = ألوان غنية؛ اللعبة مغلقة = ألوان سطح المكتب نظيفة.

#### هل سيؤدي تعديل النظام إلى إفساد نظام Windows الخاص بي؟
لا. تستخدم جميع التعديلات معلمات Windows القياسية والموثقة جيدًا. قبل تعديل أي شيء، يقوم Synchro Nova بإنشاء نقطة استعادة Windows ونسخة احتياطية من مفاتيح التسجيل المعدلة. يمكنك إرجاع كل شيء مرة أخرى إلى إعدادات Windows الافتراضية في أي وقت بالنقر فوق **"تغييرات التراجع"**.
